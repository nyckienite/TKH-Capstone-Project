Data Analyst Job Insights – Overview

This dashboard is a front-end prototype that reads two CSV files: Cleaned_DS_Jobs_enriched.csv (job postings) and Programs.csv (education programs / bootcamps). It is designed to help educators, learners, and employers quickly explore how data roles show up in the job market.

How to Use the Dashboard

  • Each item in the left-hand sidebar opens a different question about the data job market.
  • All charts are powered by the CSV files in the /data folder. You can swap in your own data as long as you keep the same column names.
  • Hover over bars and points to see exact values. You can also zoom and pan in most charts.
  • Some charts include short notes when the current dataset is missing certain fields (for example, posting dates or job platforms). Those are hints for future data collection.

Page 1 – Jobs & Platforms

Shows where jobs are located and which skills show up most by state. Use this page to answer: “Where are the jobs and what skills show up the most by region?”

Page 2 – Levels & Trends

Compares junior vs mid vs senior roles using the seniority field, and uses description length as a rough “responsibility index.” This page answers: “How do expectations change as roles get more senior?”

Page 3 – AI & Evolving Roles

Looks at how often AI is mentioned in job descriptions and how that lines up with salary, role type, and work setting (remote / hybrid / onsite, inferred from text). This page answers: “What happens to salary and role shape when AI shows up in the posting?”

Page 4 – Skills Analysis

Uses the binary skill flags (Python, Excel, Hadoop, Spark, AWS, Tableau, Big Data) to find the most common skills, which skills line up with higher average salaries, and which skill combinations travel together. This page answers: “Which skills and bundles of skills are most rewarded in this dataset?”

Page 5 – Salaries & Compensation

Breaks out median salary by job_state, seniority level, and industry, and gives a rough view of how broad the skill requirements are by company size. This page answers: “How do pay and expectations change by region, industry, and company size?”

Page 6 – Education & Candidate Fit

Compares industry demand to what programs teach (from Programs.csv), shows a rough industry–education alignment score, and lets a user type their own skills to see an estimated fit against postings and a sample program like TKH. This page answers: “Where are programs strong, where are there gaps, and how might an individual candidate fit?”

Notes About the Sample Data

  • The job data is based on a cleaned Glassdoor-style dataset for data roles. It includes salary, state, company size, industry, and binary flags for key skills like Python, Excel, and Tableau.
  • The program data is a mock snapshot of several bootcamps and degrees (including TKH) with a list of skills taught. It is only meant to illustrate what an education-alignment view could look like.
  • Where the current CSVs don’t include certain fields (for example, posting month or job platform), the dashboard shows a short message instead of a fake number. Those are intentional gaps to guide future data collection.
